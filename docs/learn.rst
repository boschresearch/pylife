************
Learn pyLife
************

pyLife is a python package, not a ready to use application. That means you
can't use plain pyLife without actually dealing with code lines. You will need
knowledge in the `Python programming language <https://www.python.org>`_ as
well as its extension packages `pandas <https://pandas.pydata.org/>`_ and
`numpy <https://numpy.org/>`_.

If you want to learn what it is like to program with pyLife you can checkout
the :doc:`tutorials <tutorials/index>`. If you want to see how to solve
specific tasks that are common in fatigue and life time assessment you can
checkout the :doc:`cookbook <cookbook>`.  To learn more about the basic
concepts and the spirit of pyLife you can read the :doc:`user guide
<user_guide>`.

In case you need support you can ask questions in our `discussion forum
<https://github.com/boschresearch/pylife/discussions>`_.
