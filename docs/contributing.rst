************************
 Contributing to pyLife
************************

pyLife is an open source projects. That means we are welcoming collaborations
with anyone who wants to improve pyLife.  You can do not only direct code
contributions but also bring in your ideas by contributing to the `discucssions
<https://github.com/boschresearch/pylife/discussions>` or by filing an issue to
the `issue tracker <https://github.com/boschresearch/pylife/issues>` if you
found a bug or think something is missing or should be done differently.

If you want to do actual code condtributions please read our contriution guide
and our coding style guide below.
